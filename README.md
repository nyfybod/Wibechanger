# Wibechanger

Графический загрузчик Dota 2 с проверкой файлов, журналом событий и настройками. Для распространения достаточно одного `Wibechanger.exe`. При первом запуске с модулем он загружает DLL из релиза GitHub и сверяет SHA-256 со значением, встроенным в EXE. Проверенная копия используется при следующих запусках. Для локальной косметики выбери «Запустить с модулем» или «Подключить к Dota 2». После подключения предметы выбираются в арсенале игры.

Файлы релизов и исходники публикуются в [nyfybod/Wibechanger](https://github.com/nyfybod/Wibechanger). Runtime, локальные предметы и журнал хранятся в `%LOCALAPPDATA%\Wibechanger\runtime\26718111`. Инструкция и лицензии встроены в EXE и доступны кнопкой «Инструкция». Действующие локальные предметы из папки старого загрузчика переносятся при первом использовании новой папки.

Wibechanger загружает сохранённые локальные предметы как уже просмотренные и добавляет новые локальные предметы с тем же статусом. Это убирает повторное уведомление о получении этих предметов при запуске.

Чтобы запустить Dota 2 без модуля, выйди из игры и выбери «Запуск без модуля» в Wibechanger или «Играть» в библиотеке Steam. Steam использует свои параметры игры. Wibechanger хранит локальные наборы рядом с DLL. Ранее добавленные предметы могут отображаться после перезапуска, если Dota сохранила их в локальном кэше арсенала. Закрытие окна загрузчика при открытой игре не завершает сессию с модулем.

В «Настройках» можно выбрать папку игры и обычный или тестовый режим. Параметры загрузчика сохраняются в `%LOCALAPPDATA%\Wibechanger\loader.ini`. Проверка файлов при открытии окна не подключает модуль. После закрытия загрузчика Dota продолжает работать. Для завершения работы самого модуля выйди из игры.

## Локальный Dota Plus

При подключении модуля включается локальное отображение Dota Plus в штатном клиенте. Для отключения добавь `plus.local=0` в `ovr_skins.cfg` в папке runtime перед запуском игры.

Локальный статус действует во время сессии с модулем. Он открывает клиентское представление Plus. Данные, которые рассчитывает Game Coordinator, зависят от доступности сервера и прав аккаунта. Получение наград, трата осколков, доступ к Battle Cup и другие серверные операции проверяются Valve.

Нативный скинченджер Dota 2 для Windows x64. Основа — [pastow/ovr-skinchanger](https://github.com/pastow/ovr-skinchanger), GPL-3.0, закреплённый коммит указан в `dependencies.lock.json`. Это самостоятельная сборка открытого проекта; исходный код Overplus не использовался и его внутренний механизм не исследовался.

Принцип: DLL работает внутри клиента, добавляет локальные предметы через эмуляцию сообщений Game Coordinator, обрабатывает экипировку и стили, подменяет отображаемую экипировку и ресурсы в игре. Предметы выбираются штатным интерфейсом Dota. Локальные предметы не становятся собственностью Steam-аккаунта.

## Целевая сборка

- Steam AppID: `570`; build ID: `26718111`.
- `ClientVersion=6976`, `SourceRevision=11246070`, `VersionDate=Nov 16 2026`.
- Windows x64, Source 2; C++20, MSVC x64, Visual Studio 2026 с CMake и Windows SDK.
- Проверенные файлы, SHA-256 и RVA: `reports/build-inspection.json`.
- Профиль загрузчика: `config/BuildProfile.h`. Сигнатуры и фиксированные структуры ядра: `vendor/ovr-skinchanger/src/Misc/Patterns.h` и `Offsets.h`. Сетевые поля сущностей разрешаются из SchemaSystem во время работы.
- При несовпадении любого из восьми хешей загрузка прекращается до записи в процесс. Перегенерация профиля после обновления сама по себе не подтверждает совместимость структур и ABI.

## Сборка и запуск

Все исходники зависимостей уже находятся в `vendor`; загрузка готовых DLL из Интернета не требуется.

```powershell
cd C:\Users\User\Desktop\Changer
.\build.ps1
.\build\bin\Release\Changer.exe --check
.\build\bin\Release\Wibechanger.exe
```

Кнопка запуска находит игру через библиотеки Steam, запускает её при необходимости и загружает `AeroChanger.dll`. Консольный `Changer.exe` сохранён для диагностики: `--attach` подключается только к уже запущенной игре; `--game "D:\SteamLibrary\steamapps\common\dota 2 beta"` задаёт путь явно.

Для отдельной тестовой сессии закрой Dota и выполни:

```powershell
.\build\bin\Release\Changer.exe --test
```

Этот режим добавляет параметры `-insecure -novid -windowed -w 1280 -h 720 -console` только при запуске новой игры. Если игра уже запущена, загрузчик использует её текущий режим.

В графическом загрузчике тот же режим доступен через «Настройки → Тестовый запуск». Кнопка «Отменить ожидание» работает до начала загрузки модуля и не закрывает запущенную игру. Во время самого подключения нужно дождаться результата. Повторный экземпляр Wibechanger открывает уже работающее окно.

В игре открой предметы героя или содержимое сокровищницы. Кнопка `+` на карточке отсутствующего предмета добавляет его в локальный инвентарь; затем прими предмет и экипируй обычной кнопкой. Арканы добавляй из конкретного слота, например `Lina → Голова → Fiery Soul of the Slayer`: на карточке арканы в `Полные наборы` добавление в тесте не сработало. Для обычного набора добавляются составляющие предметы. Стили и самоцветы обслуживает ядро открытого проекта.

## Файлы и завершение работы

```text
src/ui/                 нативный интерфейс, тема, иконка и манифест Wibechanger
src/LoaderService.*     общий механизм запуска и подключения для GUI и CLI
src/                    проверка сборки, консольная оболочка, точка входа DLL
config/BuildProfile.h    закреплённые хеши целевой сборки
tools/Inspect-Build.ps1  повторяемая проверка сигнатур и экспортов V8
vendor/ovr-skinchanger/  ядро и SDK, включая локальные исправления
vendor/protobuf/        компилятор и библиотека Protobuf 3.21.12
vendor/protos/dota2/     описания сообщений Dota 2
reports/                наблюдения и результаты проверок
build/bin/Release/      Wibechanger.exe, Changer.exe, AeroChanger.dll
```

`ovr_skins.cfg` и `ovr_skins.log` создаются рядом с DLL в папке runtime. Настройки предметов сохраняются заменой временного файла. Не запускай несколько копий DLL из разных директорий в одну игру.

Для завершения работы DLL выйди из Dota. Выгрузка через `FreeLibrary` во время игры не поддерживается: клиент может хранить ссылки на локальные объекты и обработчики. Файлы игры на диске не патчатся. Для сброса локального инвентаря после выхода из игры переименуй `ovr_skins.cfg`.

## Проверки

Фактически выполненные проверки и их границы записаны в `reports/VALIDATION.md` (в архиве для запуска — `VALIDATION.md`). Совпадение сигнатур, успешная компиляция и сообщение `READY` по отдельности не доказывают правильное отображение скинов в матче. Совместимость с обновлениями и отсутствие обнаружения не гарантируются.

Проверки графического загрузчика: `reports/LOADER-VALIDATION.md`. Сборка GUI использует Win32, Direct2D и DirectWrite из Windows SDK; дополнительные графические библиотеки не нужны.

Проверены в деморежиме: `Phantom Balladeer` для Abaddon, `Fiery Soul of the Slayer` для Lina и аркана Phantom Assassin. Матчмейкинг и удалённый сервер не проверялись. При запуске лучше подключать DLL в главном меню, до входа в матч.

Повторная инспекция файлов без изменения профиля:

```powershell
.\tools\Inspect-Build.ps1 -GameRoot 'D:\SteamLibrary\steamapps\common\dota 2 beta'
```

`-WriteProfile` предназначен для переноса на исследованную сборку; проверка структур и поведения после такого переноса обязательна.
